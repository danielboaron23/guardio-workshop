מתקינים את Xcode

כשעה, רובה המתנה · חינם

Xcode היא התוכנה של Apple שמכילה את הסימולטור: iPhone וירטואלי שרץ על המחשב. בו נראה את האפליקציה.

  1. פתחו את ה-App Store במחשב וחפשו Xcode, או היכנסו ישר לעמוד של Xcode.
  2. לחצו Get ואז Install, וחכו שההורדה תסתיים.
  3. פתחו את Xcode. בפתיחה הראשונה הוא מציג את תנאי השימוש ומציע להתקין רכיבים: אשרו את התנאים, ודאו ש-iOS מסומן, ולחצו Download & Install.
  4. בתפריט העליון: Xcode → Open Developer Tool → Simulator.
✅
איך יודעים שזה עבד?נפתח חלון עם iPhone על המסך. אפשר לסגור אותו.

מתקינים את Node.js

5 דקות

Node.js הוא המנוע שמריץ את הפרויקט על המחשב. מתקינים אותו פעם אחת ושוכחים ממנו.

  1. היכנסו ל-nodejs.org והורידו את הגרסה שמסומנת LTS.
  2. פתחו את הקובץ שירד ולחצו Continue עד הסוף.
  3. עכשיו נבדוק שזה עבד. פתחו את ה-Terminal: לחצו ⌘ Command + רווח, הקלידו Terminal ולחצו Enter.
  4. העתיקו את השורה הבאה, הדביקו בחלון שנפתח ולחצו Enter:
node -v
✅
איך יודעים שזה עבד?מופיע מספר גרסה, למשל v24.14.0. המספר הראשון צריך להיות 22 ומעלה.
השאירו את חלון ה-Terminal פתוח. נשתמש בו גם בצעד הבא.

מתקינים את pnpm

2 דקות

pnpm הוא כלי קטן שמוריד את כל החלקים שהפרויקט צריך.

  1. ב-Terminal, הדביקו את השורה הבאה ולחצו Enter:
sudo npm install -g pnpm
המחשב יבקש סיסמה. זו הסיסמה שאיתה אתם נכנסים ל-Mac, והיא נדרשת כי מתקינים כלי לכל המחשב. כשמקלידים אותה לא רואים כלום על המסך, וזה תקין. הקלידו ולחצו Enter.
  1. בדקו שזה עבד:
pnpm -v
✅
איך יודעים שזה עבד?מופיע מספר גרסה, למשל 10.30.3.

מורידים את הפרויקט, בעזרת Claude

5 דקות

את הפרויקט של הסדנה נוריד כבר דרך Claude, בדיוק כמו שנעבוד בסדנה: מבקשים במילים, והוא עושה. ודאו קודם ש-Xcode סיים להתקין ושפתחתם אותו פעם אחת (צעד 1).

  1. פתחו את Finder, היכנסו לתיקיית Documents וצרו בה תיקייה חדשה וריקה בשם guardio-workshop.
  2. פתחו את אפליקציית Claude והיכנסו לטאב Code.
  3. בחרו את התיקייה guardio-workshop שיצרתם.
  4. העתיקו את המשפט הבא, הדביקו בתיבת ההודעה ושלחו:
Clone https://github.com/danielboaron23/guardio-workshop.git into this folder and run pnpm install.
  1. לפני ש-Claude מריץ משהו על המחשב, הוא מציג מה הוא עומד לעשות ומבקש את האישור שלכם. קראו את הבקשה. כאן היא אמורה להיות הורדה של הפרויקט והתקנה שלו.
חשוב שהתיקייה תהיה ריקה ושתבחרו בדיוק אותה, ולא את Documents כולה. כך Claude ימצא את הפרויקט גם בצעד הבא.
✅
איך יודעים שזה עבד?Claude כותב שההורדה וההתקנה הסתיימו, ובתיקייה guardio-workshop מופיעים קבצים ותיקיות, למשל apps ו-packages.

הכול מותקן ועובד. נתראה בסדנה! אם משהו השתבש בדרך ולא הסתדר, שלחו לדניאל צילום מסך לפני הסדנה.

נתקעתם? זה קורה

אין לי Mac, או ש-Xcode לא מצליח להתקין

אפשר עדיין להשתתף. דלגו על צעד 1 והמשיכו בשאר הצעדים: האתר וה-Storybook יעבדו רגיל. את האפליקציה תראו בטלפון שלכם: התקינו בו את האפליקציה Expo Go מחנות האפליקציות, ובסדנה נסרוק יחד קוד QR. עדכנו את דניאל מראש.

אין לי מספיק מקום במחשב ל-Xcode

צריך בערך 25GB פנויים. בדקו ב-System Settings → General → Storage מה תופס מקום, ומחקו קבצים גדולים או רוקנו את האשפה.

ב-Terminal כתוב "command not found"

בדרך כלל זה אומר שההתקנה של הצעד הקודם לא הסתיימה. סגרו את ה-Terminal, פתחו אותו מחדש ונסו שוב. אם זה חוזר, חזרו על הצעד של Node.js (צעד 3).

ההתקנה של pnpm נכשלה (EACCES או permission denied)

ודאו שהעתקתם את השורה כולה, כולל המילה sudo בהתחלה, ושהקלדתם את הסיסמה של ה-Mac. אם במחשב העבודה שלכם אין לכם הרשאת מנהל, בקשו עזרה מה-IT של החברה או שלחו לדניאל צילום מסך.

ההורדה של הפרויקט נכשלת, או מבקשת להתקין כלים

זה קורה כש-Xcode עוד לא נפתח אחרי ההתקנה. פתחו את Xcode, אשרו את תנאי השימוש, חכו שיסיים להתקין רכיבים, ואז בקשו מ-Claude לנסות שוב.

אם Claude כותב שהתיקייה לא ריקה, ודאו שבחרתם את התיקייה החדשה שיצרתם ולא תיקייה אחרת.

בסימולטור כתוב "Project is incompatible with this version of Expo Go"

מותקנת גרסה ישנה של Expo Go. בסימולטור, לחצו לחיצה ארוכה על האייקון של Expo Go, בחרו Remove App, ואז בקשו מ-Claude להריץ שוב את אפליקציית המובייל.

Claude כותב שפורט תפוס (Port is in use)

תוכנה אחרת במחשב משתמשת באותו ערוץ. סגרו פרויקטים אחרים שרצים אצלכם ונסו שוב, או שלחו לדניאל צילום מסך.

משהו אחר לא עובד

צלמו את המסך עם ההודעה שקיבלתם ושלחו לדניאל, עם מספר הצעד שבו נתקעתם. עדיף לפני יום הסדנה, כדי שנספיק לפתור.
